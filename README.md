# Garden Route Garage Doors

Premium static website for Garden Route Garage Doors, a garage door company based in Mossel Bay and serving the Garden Route.

The site is built with pure HTML, CSS and vanilla JavaScript. It does not require a framework, build command or package manager.

## Included Files

- `index.html` - homepage markup and SEO metadata
- `styles.css` - responsive layout, premium visual styling and animations
- `script.js` - mobile navigation, scroll reveal and form feedback
- `vercel.json` - Vercel static deployment configuration
- `assets/` - local SVG brand and background assets

## Services Highlighted

- Garage Door Installation
- Garage Door Repairs
- Garage Door Servicing & Maintenance
- Garage & Gate Automation
- Roll-Up Garage Doors
- Aluminium Garage Doors
- Aluzinc Garage Doors
- Wooden Garage Doors

## Service Areas

Mossel Bay, Hartenbos, Dana Bay, George, Great Brak River, Klein Brak River and surrounding Garden Route areas.

## Deploying on Vercel

Import this repository into Vercel and deploy it as a static site. No build command is required. The homepage is served from `/` using the root `index.html` file.

## Launch Notes

The phone, WhatsApp and email values are placeholders. Update these in `index.html` before publishing the final live website.
